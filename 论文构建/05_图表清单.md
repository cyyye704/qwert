# 正式图表清单

## 1. 扫描范围与采用规则

- 用户指定的最终图片实际位于 `new_figures_main/`；项目中未发现同级 `new_figures/` 目录。
- `new_figures_main/FIGURE_AUDIT.md` 记录 11 张 PNG 全部通过最终图表审计；本轮又逐张进行了视觉检查。
- `results/summary.md`、根目录 `summary.json`、其他 JSON/CSV 和 Excel 只作为图中数字核验源，不自动获得“正文图表”资格。
- 第一版论文及 `paper_draft_legacy/figures/` 中的图片均属于历史版本，不允许替代最终图片。
- 采用标准：每张图必须能支持一个明确且不重复的论证；只有装饰作用的图不进入正文。

## 4. Q1 图表缺口

- `new_figures_main/` 中没有 Q1 图片。
- Q1 的正式数值表可由 `result1.xlsx` 和 `results/problem1.json` 支撑；正文可以只放表格，不强制放图。
- 若最终排版要求每问至少一图，需要在后续阶段由最终 Q1 数据生成并加入最终图片目录。第一版论文的旧 Q1 图不得直接顶替。
- 该项属于呈现层决策，不影响 Q1 数学事实和本阶段完成。

## 6. 单位、文字与数字审计结论

- 11 张最终 PNG 的曲线、数字和图例与 `FIGURE_MANIFEST.md` / `FIGURE_AUDIT.md` 记录一致，未发现必须重画的数据错误。
- Q3_F3 的 `No update`、Q4_F1 的英文类别、Q4_F3 的 `causal` 属于可选语言统一，不改变证据。
- Q4_F1 中“完美信息”类别在正文和图注中暂应称“完美信息基准”，是否改为“下界”取决于严格口径确认。
- Q2_F1 中计划与最终常规购电曲线重合不是重复绘图错误，而是 Q2 不允许日内调整的直接结果。
- 所有功率图必须在图注写明单位为 kW；所有费用比较写明单位为元；SOC 图写明 kWh 或百分比的实际绘制口径。
